# 阶段 7.6-D：候选岗位人工加入待确认区

## 本步目标

把公开岗位候选预览与现有暂存审核流程连接起来，同时继续保持人工确认边界。

## 已完成

- 完整 JD 展开后显示“加入待确认区”按钮。
- 点击按钮只写入 D 盘采集暂存文件，不直接进入正式岗位数据库。
- 同一来源岗位和相同正文再次加入时自动跳过，不重复写入。
- 加入后刷新待确认列表，仍需人工选择“确认导入”或“丢弃”。
- 后端继续只允许已审核的 Moka 企业和合法 UUID 岗位编号。

## 不在本步范围

- 不做无人值守批量采集。
- 不自动导入正式岗位库。
- 不自动修改简历。
- 不新增 Boss 直聘自动抓取。

## 验收方式

1. 点击“发现元戎启行候选”。
2. 展开任意候选的完整 JD。
3. 点击“加入待确认区”。
4. 页面顶部待确认数量增加，岗位出现在暂存列表。
5. 再次操作同一岗位时，不产生重复记录。
