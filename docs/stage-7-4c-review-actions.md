# 阶段 7.4-C：人工确认导入与丢弃

状态：待用户确认

## 本步骤完成的内容

- 待确认岗位增加“确认导入”和“丢弃这条”；
- 只有通过核心画像准入的岗位可以确认导入；
- 未通过准入的岗位在前后端都会阻止导入，不能只绕过按钮；
- 导入时保留来源、公司、链接、发布时间、地区和薪资等已有字段；
- 导入完成后暂存记录标记为 `imported`；
- 已存在的相同 JD 标记为 `duplicate`，不会重复写入；
- 丢弃需要用户二次确认；
- 丢弃不是物理删除，记录标记为 `discarded` 并写入本地审核事件日志；
- 已处理记录不再出现在“待确认采集”列表。

## 安全边界

- 系统不会替用户自动点击导入或丢弃；
- 当前 Anthropic 岗位未通过核心画像准入，因此导入按钮保持禁用；
- 正式岗位库只有在用户点击并且后端再次校验通过后才会改变；
- 审核记录继续保存在 D 盘私人数据目录，不进入 Git。
