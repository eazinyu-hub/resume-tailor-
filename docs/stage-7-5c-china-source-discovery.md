# 阶段 7.5-C：国内公开招聘来源调查

状态：待用户确认  
核对日期：2026-09-16

## 1. 本步骤目标

寻找比海外 Greenhouse、Lever 岗位更贴近国内求职市场的公开招聘来源，并区分：

- 页面能够公开查看；
- 存在官方职位读取接口；
- 适合后续使用 Firecrawl 读取；
- 仍然只能由用户手动导入。

本步骤只调查来源和候选岗位，不采集岗位、不修改数据库、不改变岗位画像。

## 2. 发现的来源类型

### Moka 企业招聘官网

Moka 为国内企业提供公开社招和校招页面，并发布了招聘官网 API 文档。官方文档包含按企业 `orgId` 获取职位列表和单个职位信息的接口。

已验证的现象：

- 月之暗面、元戎启行、微步在线等企业的公开职位列表可以从 Moka 招聘官网接口读取；
- 不同企业配置不同，同一接口可能公开返回，也可能返回 `IP not allowed`；
- Moka 的 `robots.txt` 当前只单独禁止少数招聘站路径，没有一刀切禁止全部招聘页；
- robots 未禁止不等于自动获得采集授权，仍需逐个企业建立白名单；
- Moka 开放平台也存在 API Key 和 OAuth 鉴权机制，因此不能把所有接口都理解成匿名公共接口。

当前状态：`paused_review`。下一步只选择一个能够匿名读取、岗位高度相关的企业做单条试采评审，不批量遍历 Moka 客户。

官方资料：

- <https://www.mokahr.com/docs/api/>
- <https://app.mokahr.com/robots.txt>

### 企业自建招聘官网

字节跳动、百度、月之暗面等企业拥有自己的公开招聘入口。

- 百度职位详情能够公开查看，当前存在与 AI 应用、Agent、自动化高度相关的社会招聘岗位；
- 月之暗面自建招聘首页最终链接到 Moka 职位系统，可以优先研究 Moka 的公开职位接口；
- 字节跳动招聘官网存在 AI 应用、AI Coding 等方向，但当前没有确认适合本项目的公开职位 API；
- 自建官网如果没有明确公开 API，只能先保持 `paused_review`，以后再判断是否适合低频 Firecrawl 单页读取。

### 综合招聘平台

BOSS 直聘、猎聘等综合平台仍不作为自动采集目标。BOSS 继续保持 `manual_only`，由用户手动复制或导入自己看到的岗位。

## 4. 第一条国内试采建议

推荐下一小步只试采：

- 公司：深圳元戎启行科技有限公司
- 岗位：AI 研发效能工程师
- Moka `orgId`：`deeproute`
- 岗位 ID：`57eddbd2-5e18-4b7f-b2b6-e9996a696724`
- 更新时间：2026-08-03

推荐原因：

1. 岗位能力与现有国内样本中的 AI 工具开发、内部智能化系统和 Vibe Coding 高度重合；
2. 明确点名 Cursor、Claude Code、Codex，而不是只笼统写“熟悉 AI”；
3. 同时强调业务痛点、工具落地、Agent、内部工具链、效果度量和培训推广；
4. 没有明确写 3 年或 5 年工作经验，适合作为目标方向样本；
5. 岗位仍要求本科及相关专业，系统应把它识别为个人门槛，而不能误当成已满足事实。

## 5. 计划中的采集边界

如果用户确认进入下一小步，Moka 单条试采必须满足：

- 新增独立的 Moka 来源策略和企业白名单；
- 白名单最初只加入 `deeproute`；
- 只允许指定岗位 UUID，不允许遍历全部 Moka 企业；
- 只调用官方文档中的招聘官网职位接口；
- 收到 `401`、`403`、`429`、`IP not allowed` 或风控响应立即停止；
- 不使用 API Key、OAuth、Cookie、登录态、代理或绕过措施；
- 结果只进入 D 盘暂存区，必须人工确认；
- 先验证职位仍然开放、正文完整、地区与学历年限没有丢失；
- 未经过用户确认，不进入正式岗位库和岗位画像。

## 6. Firecrawl 的位置

Firecrawl 不是国内岗位来源，只是页面读取工具。

- 有官方公开 JSON 接口时，优先使用接口，不使用 Firecrawl；
- 没有公开接口、但企业官网允许访问时，才评估 Firecrawl 单页读取；
- 页面依赖登录、验证码、Cookie 或平台规则禁止自动访问时，不使用 Firecrawl；
- Firecrawl 不能改变 BOSS 直聘的 `manual_only` 边界。

## 7. 当前结论

- 国内公开招聘来源足够支持下一轮试点，不需要只依赖海外岗位；
- Moka 是目前最有价值的国内候选来源，但必须按企业逐个审核；
- 元戎启行的 AI 研发效能工程师是当前最合适的第一条国内试采对象；
- 百度、字节等自建招聘官网先作为人工研究来源，不急着写通用爬虫；
- 国内岗位画像仍以用户手动导入的 BOSS 等真实岗位为主，自动来源只做补充。
