# 阶段 7.2：独立采集器骨架

状态：待用户确认

## 本步骤完成的内容

- 新增与 FastAPI 主应用分离的 `backend/collector` 包；
- 定义统一的岗位暂存记录和内容指纹；
- 建立来源状态检查，BOSS 直聘固定为 `manual_only`；
- 添加本地模拟来源，用于在不联网时验证完整写入流程；
- 暂存结果默认写入 `D:\AI\resume-tailor-data\collector-staging\pending-jobs.jsonl`；
- 为普通 HTTP 和 Firecrawl 预留统一读取接口；
- 两种网络读取器当前都会明确拒绝运行，不发送网络请求；
- 添加自动化测试，验证合规开关、暂存格式和禁用状态。

## 当前数据流

```text
本地模拟来源
  -> 来源状态检查
  -> 标准化岗位记录
  -> JSONL 暂存区
  -> pending（等待未来人工确认）
```

本步骤没有连接岗位数据库，也没有让暂存记录参与岗位画像。

## 为什么暂时保留两种读取器

- 普通 HTTP：以后用于结构简单、明确允许访问的公开招聘页；
- Firecrawl：以后用于合规但 JavaScript 较重、正文难提取的页面；
- 来源是否允许采集由本项目的来源策略控制，不能由读取工具决定。
