- 模型：deepseek-flash
- 每个案例由用户单独确认后调用一次
- 不自动重试
- 生成阶段不修改正式草稿
- 只在 Git 忽略的独立演示数据目录中应用

## 成对结论

- 两次真实 API 调用均一次成功，总用量 2997 tokens，没有自动重试。
- 两份草稿分别绑定两个岗位，读取时没有串稿。
- 工具自动化版本优先突出批量处理、重复识别、定时任务和验证。
- Vibe Coding 版本优先突出独立交付、全栈实现和可编辑/可导出的产品闭环。
- 两份描述共享真实适用的事实，但不是只替换岗位名称。
- 两个岗位的 Word 与 PDF 均可生成；是否严格保持一页仍需视觉渲染检查。
- 真实 JD 曾出现的一次 502 尚未复现；当前判断是特定模型输出没有通过严格事实校验，而不是后端版本或应用接口故障。
