# 小步骤 3.1：岗位样本关键词频率

首页岗位列表上方展示统计，可刷新、展开和收起；导入岗位返回首页后重新读取。

首版六项：Codex、Agent、Python、React、部署、调试。

## 计数口径

- **提及 JD 数**：同一关键词在一份纳入的 JD 中只计一份。
- **原文次数**：累计纳入 JD 正文中的匹配次数。
- **样本占比**：提及 JD 数 / 纳入 JD 数；保留一位小数，空样本返回零。
- 只统计正文，不统计岗位名称。英文忽略大小写，使用英文单词边界；例如 React.js 命中 React，Preact 不命中。
- Agent 合并 Agent、Agents 和“智能体”；其他词按字面匹配。
- 否定表述、举例和加分项仍属于“提及”，不解释为必须具备的能力。
- 每项附对应岗位、单份出现次数和首处命中附近的正文片段。片段保留大小写，统一全半角。

## 样本口径

排除已标记 duplicate、存在 duplicate_of、invalid 或空正文的记录。其余正文在统一全半角、大小写并忽略空白后相同的，只纳入 ID 最小的一条。所有计算在内存完成，不修改状态或删除岗位。

尚未确认的近似重复仍然纳入；无法从本统计推导独立公司数量。页面明确展示纳入数和排除数，结论仅适用于当前样本库。

## 实现和验证

- `GET /api/market/keyword-frequency` 实时只读 SQLite，不依赖岗位分类或已有分析记录。
- 统计逻辑独立于单岗位简历匹配；本步结果用于展示，还未参与简历打分或改写。
- 测试覆盖重复提及、分母、正文去重、否定句、英文边界、空库、导入后更新以及数据库未被改写。
- 测试临时数据库存放在仓库已忽略的 `work/test-market-profile`，真实 JD 不进入仓库。
