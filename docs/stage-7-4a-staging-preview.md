# 阶段 7.4-A：待确认采集只读预览

状态：待用户确认

## 本步骤完成的内容

- 后端增加只读暂存区接口 `GET /api/collector/staging`；
- 主界面增加“查看待确认采集”入口；
- 单独页面展示待确认岗位数量、来源、公司、地点和更新时间；
- 点击岗位后在对应卡片下展开完整 JD；
- 可打开公开岗位原链接；
- 页面明确提示岗位尚未进入正式岗位库和岗位画像；
- 暂存文件损坏时明确报错，不静默丢失记录；
- 限制单次读取的文件大小与记录数量。

## 本步骤没有做什么

- 没有导入按钮；
- 没有丢弃或删除按钮；
- 没有修改正式数据库；
- 没有触发新的网络采集；
- 没有让暂存岗位参与市场画像和 Agent 分析。

下一步确认页面位置和 JD 展开体验后，再分别增加“确认导入”和“丢弃”动作。
